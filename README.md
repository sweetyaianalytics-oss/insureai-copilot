# InsureAI Copilot

Agentic AI Health Insurance Claims Audit Assistant.

Student capstone prototype using synthetic data only.

## Current MVP workflow
1. Upload/select claim and policy data
2. Check member eligibility
3. Review policy details
4. Review claim information and selected code/rule mismatches
5. Show findings with reasons and sources
6. Send flagged cases to a human reviewer
7. Mark clean cases as ready for the next processing step

Step 1 implemented:
- Synthetic member, policy, and claim data
- Eligibility checker
- Five test cases
